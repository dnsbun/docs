# DNSbun documentation

DNSbun is a hosted dynamic DNS fan-out service. This site will contain the
guides and reference material for configuring and using DNSbun.

!!! note

    The documentation is just getting started. More guides are on the way.

## About this repository

The documentation is written in Markdown and built with
[Zensical](https://zensical.org/). Use the edit button on any page to suggest
an improvement.
